Pekacubos

Un mundo de cubos para romper y construir
Móvil: joystick a la izquierda, arrastra a la derecha para mirar; toca para poner o usar, mantén pulsado para romper o golpear; 🎒 abre el inventario y las recetas.
PC: WASD para andar, espacio para saltar, ratón para mirar; clic izquierdo rompe, clic derecho pone; 1–9 o rueda para elegir; E abre el inventario. Usa la mesa de trabajo y el horno cerca para más recetas.
